# Chegada — Onboarding e acompanhamentos

Aplicação de RH para gestão de colaboradores, simulador de onboarding e questionários de acompanhamento em 7, 20, 45, 90 e 120 dias.

## Privacidade

Este repositório não contém nomes, matrículas, e-mails ou respostas de colaboradores. A base deve ser importada pelo painel administrativo autenticado depois da implantação e é armazenada no disco persistente do Render.

## Implantação

O `render.yaml` cria um Web Service Docker com disco persistente. Durante a aprovação do Blueprint, informe `ADMIN_PASSWORD` e `OPENAI_API_KEY` diretamente no Render.
